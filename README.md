# hitoma-works.github.io

個人開発の屋号「hitoma works」の公式サイトです。https://hitoma.works

- [Astro](https://astro.build/) の静的サイトです。`master` に push すると GitHub Actions がビルドして GitHub Pages に出します。
- 手元では Node 22.12 以上で `npm ci` → `npm run dev`（確認用）／`npm run build`（`dist/` を作って点検）。
- アプリの足し方などの決まりは [CLAUDE.md](CLAUDE.md) にあります。
